# OrionVim

<img src="https://github.com/user-attachments/assets/c6251e26-031b-44ab-8ca3-cc2a0e7a04c1" alt="Dashboard">

Custom neovim configuration aimed to semplicity and ease of use.
Comes preinstalled with a wide compatibility with most modern programming languages.

## Keymaps
| Description | Command | Mode |
|------------|--------|------|
| Paste without overwriting clipboard | <kbd>p</kbd> | Visual |
| Save file | <kbd>Ctrl</kbd> + <kbd>S</kbd> | Normal, Insert, Visual |
| Start search | <kbd>Ctrl</kbd> + <kbd>F</kbd> | Normal |
| Clear search highlight | <kbd>Esc</kbd> | Normal |
| Enter command mode | <kbd>;</kbd> → <kbd>:</kbd> | Normal |
| Next buffer | <kbd>Tab</kbd> | Normal |
| Previous buffer | <kbd>Shift</kbd> + <kbd>Tab</kbd> | Normal |
| Toggle file explorer (NvimTree) | <kbd>Ctrl</kbd> + <kbd>N</kbd> | Normal |
| Move focus left | <kbd>Ctrl</kbd> + <kbd>H</kbd> | Normal |
| Move focus right | <kbd>Ctrl</kbd> + <kbd>L</kbd> | Normal |
| Move focus down | <kbd>Ctrl</kbd> + <kbd>J</kbd> | Normal |
| Move focus up | <kbd>Ctrl</kbd> + <kbd>K</kbd> | Normal |
| Telescope recent files | <kbd>Leader</kbd> + <kbd>F</kbd> <kbd>O</kbd> | Normal |
| Telescope find files | <kbd>Leader</kbd> + <kbd>F</kbd> <kbd>F</kbd> | Normal |
| Telescope live grep | <kbd>Leader</kbd> + <kbd>F</kbd> <kbd>W</kbd> | Normal |
| Code actions (LSP) | <kbd>Leader</kbd> + <kbd>C</kbd> <kbd>A</kbd> | Normal |
| Go to definition | <kbd>Leader</kbd> + <kbd>G</kbd> <kbd>D</kbd> | Normal |
| Rename symbol | <kbd>Leader</kbd> + <kbd>R</kbd> <kbd>A</kbd> | Normal |
| Comment line | <kbd>Leader</kbd> + <kbd>/</kbd> | Normal |
| Comment selection | <kbd>Leader</kbd> + <kbd>/</kbd> | Visual |
| Copy to system clipboard | <kbd>y</kbd> | Normal, Visual |
| Copy line to system clipboard | <kbd>yy</kbd> | Normal |
| Copy to end of line | <kbd>Y</kbd> | Normal |
| Exit terminal mode | <kbd>Esc</kbd> + <kbd>Esc</kbd> | Terminal |
| Close buffer | <kbd>Leader</kbd> + <kbd>X</kbd> | Normal |
| Select all | <kbd>Ctrl</kbd> + <kbd>A</kbd> | Normal|
| Vertical split (≥2 buffers) | <kbd>Leader</kbd> + <kbd>V</kbd> | Normal |
| Horizontal split (≥2 buffers) | <kbd>Leader</kbd> + <kbd>H</kbd> | Normal |
